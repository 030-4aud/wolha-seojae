# 月下書房 · 월하서재

단일 HTML 파일로 구성된 정적 웹사이트입니다.

## GitHub에 업로드
1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 커밋합니다.

## GitHub Pages로 공개하기
1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 `main`, 폴더를 `/(root)`로 지정하고 저장합니다.
4. 배포가 완료되면 GitHub Pages 주소에서 사이트를 확인할 수 있습니다.

## 참고
- 별도 로컬 이미지/스크립트 파일 없이 `index.html` 하나에 주요 코드가 포함되어 있습니다.
- Google Fonts를 사용하므로 인터넷 연결이 필요합니다.
