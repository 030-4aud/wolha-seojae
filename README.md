# 月下書房 · 월하서재

이리와 삼영, 두 사람만의 달빛 창작 서재.
글·그림·할 일·기록을 한곳에 모아 두는 개인 아카이브 사이트입니다.

## 공간

| 이름 | 한자 | 하는 일 |
|---|---|---|
| 월하당 | 月下堂 | 홈 — 일곱 공간 카드, 최근 글, 오늘의 일정 |
| 월문각 | 月文閣 | 글 서가 — 분류·검색, 글 읽기 |
| 월필당 | 月筆堂 | 글쓰기 — 서식 편집기, 글자 수 세기, 스토리보드 |
| 월화첩 | 月畫帖 | 그림 화첩 |
| 월장각 | 月藏閣 | 폴더 보관소 |
| 월사록 | 月事錄 | 할 일 목록 |
| 월흔록 | 月痕錄 | 달력 기록 |

### 월필당 기능

- **글자 수 세기**: 공백 포함 / 공백 제외를 함께 표시하고, 드래그한 부분만 따로 셉니다. 숫자를 누르면 어절·문단·줄·원고지 매수를 보여 주며, 상태줄에 보일 방식을 고를 수 있습니다.
- **스토리보드**: 「단편 | 주요 인물 | 제목 : 글쓴이 | 비고」 표로 장면을 짭니다. 장면 번호 자동, 장면·단편 추가/이동/삭제, 강조색, A4 인쇄·PDF 저장을 지원합니다.

## 실행

빌드 과정 없이 `index.html` 한 파일로 동작합니다. 그림과 로고도 파일 안에 들어 있습니다.

- 내 컴퓨터: `index.html`을 브라우저로 엽니다.
- 웹에 올리기: 아래 GitHub Pages 방법을 따릅니다.

## GitHub Pages로 배포

1. GitHub에서 새 저장소를 만듭니다 (예: `wolha-seojae`).
2. **Add file → Upload files**에서 이 폴더의 파일을 모두 끌어다 놓고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 *Source*를 `Deploy from a branch`, *Branch*를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/wolha-seojae/` 주소로 열립니다.

터미널을 쓴다면:

```bash
git init
git add .
git commit -m "월하서재 첫 업로드"
git branch -M main
git remote add origin https://github.com/<아이디>/wolha-seojae.git
git push -u origin main
```

## 데이터는 어디에 저장되나요?

쓴 글·그림·할 일·기록은 **각자의 브라우저(localStorage)** 에만 저장되고, GitHub 저장소에는 올라가지 않습니다.

- 다른 기기나 다른 사람에게 옮길 때는 **설정 → 데이터 내보내기**로 파일을 만들고, 받는 쪽에서 **데이터 가져오기**를 합니다.
- 브라우저 저장 공간은 약 5MB라서, 큰 그림을 많이 올리면 가득 찰 수 있습니다.
- 내보낸 백업 파일은 `.gitignore`에 넣어 두어 실수로 저장소에 올라가지 않게 했습니다.
